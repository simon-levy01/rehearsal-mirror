# Dependency and model attribution

- **Transformers.js 3.8.1**, official `@huggingface/transformers` npm package, Hugging Face; **Apache License 2.0**. [Source](https://github.com/huggingface/transformers.js), [official docs](https://huggingface.co/docs/transformers.js). Licence retained in `licenses/transformers-APACHE-2.0.txt`.
- **Xenova/all-MiniLM-L6-v2**, Transformers.js-compatible ONNX conversion of the Sentence Transformers model; **Apache License 2.0**. [Pinned model source](https://huggingface.co/Xenova/all-MiniLM-L6-v2/tree/751bff37182d3f1213fa05d7196b954e230abad9). Revision `751bff37182d3f1213fa05d7196b954e230abad9`, q8 `onnx/model_quantized.onnx`. Public API reports `gated: false`. Full source card retained unchanged in `MODEL-CARD.md`; model files themselves are not redistributed in this source repository.
- **sentence-transformers/all-MiniLM-L6-v2**, upstream pretrained English sentence embedding model by the Sentence Transformers authors; **Apache License 2.0**. [Source and model card](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2). Intended for semantic search, producing 384-dimensional vectors; not a hiring, language-assessment or factual-validation model.
- **ONNX Runtime Web**, Microsoft and contributors; **MIT**, used by Transformers.js for browser inference. Installed version `1.22.0-dev.20250409-89f8206ba4`, locked transitively. [Source/licence](https://github.com/microsoft/onnxruntime/blob/main/LICENSE). The build process bundles runtime JS and WASM in the generated static build.
- **Vite 7.1.7**, MIT, build tooling; [source](https://github.com/vitejs/vite). **Playwright 1.58.2**, Apache-2.0, verification tooling; [source](https://github.com/microsoft/playwright). Vite is needed to build from source; neither tool is needed to serve an already-built preview with Python.

The app's MIT licence applies to original app code only. Preserve dependency notices and follow their separate licences. `package-lock.json` pins the complete build/test dependency tree. Bundled production dependency licences are retained under `licenses/`.
